# TURA

**Правовая система Казахстана.** Отвечает на юридические вопросы со ссылкой на
конкретную норму, составляет и проверяет договоры, готовит законопроекты по
государственным стандартам РК и разбирает общественные комментарии к ним.

Система не сочиняет ответ: она ищет в реальных нормативных актах и указывает
источник — закон, статью, пункт.

---

## Что умеет

| Модуль | Назначение |
|---|---|
| **Консультант** | Вопрос на русском, казахском или английском — ответ с гибридным поиском по корпусу НПА и ссылками на нормы |
| **Рабочее место** | Библиотека личных документов, объединение в дела, диалог с собственным договором с опорой на нормы РК |
| **Договоры** | Составление по 9 типам и проверка загруженного договора с оценкой рисков |
| **Законопроекты** | 13 обязательных разделов по стандартам РК, версии, экспорт в PDF / DOCX / XLSX |
| **Аналитика** | Разбор массивов общественных комментариев: темы, тональность, риски и противоречия |
| **Публичное API** | Доступ к договорным функциям по ключу |

## Технологии

- **Бэкенд:** Python 3.12, Flask
- **База:** PostgreSQL 16 + pgvector — и документы, и векторы в одном месте
- **Поиск:** гибридный — семантический по эмбеддингам BGE-M3 (1024) плюс ключевой
- **Модель:** своя дообученная, развёрнута на централизованном vLLM-стеке;
  слой `llm_providers/` абстрагирует провайдера (локальный vLLM, Ollama, OpenAI)
- **Фронтенд:** React 19 + TypeScript + Vite, собственная дизайн-система без UI-фреймворков
- **Развёртывание:** Docker Compose, Cloudflare Tunnel

## Быстрый старт

Требуется Docker и Node 20+.

```bash
git clone https://github.com/nurkal022/law_rag.git
cd law_rag
cp .env.example .env          # пропиши SECRET_KEY, ADMIN_PASSWORD, адреса LLM и эмбеддингов
docker compose up -d          # поднимает PostgreSQL с pgvector и приложение
```

Приложение отвечает на `http://localhost:5003`, проверка живости — `/healthz`.

### Фронтенд

```bash
cd frontend
npm install
npm run dev        # разработка на http://localhost:5173, /api проксируется на Flask
npm run build      # сборка в ../static/app, которую отдаёт Flask
npm run check      # проверка типов + защита дизайн-системы
```

## Дизайн-система

Внешний вид подчинён направлению **«Документ»**: официальность достигается
типографикой, а не корпоративным синим. Тёплая бумага вместо серо-голубого фона,
антиква в заголовках и нормах, тонкие линии вместо карточек и теней, один
сдержанный акцент цвета печати.

Гарнитуры — PT Serif, Golos Text и JetBrains Mono: у первых двух кириллица
нарисована изначально, а не достроена к латинице, поэтому казахские буквы
(ә, ғ, қ, ң, ө, ұ, ү, һ, і) сидят в строке ровно.

Роли закреплены жёстко: **PT Serif** — смысловой текст (заголовки, нормы,
ответы), **Golos Text** — весь интерфейс, **JetBrains Mono** — только правовые
координаты вроде `ГК РК 178.1`. Моноширинный работает как навигация: отделяет
адресуемую норму от человеческого текста без цветового выделения.

Все значения живут в `frontend/src/styles/tokens.css`. Литералы в компонентах
запрещены и отлавливаются проверкой:

```bash
npm run lint:tokens
```

Полное описание — [docs/superpowers/specs/2026-09-05-tura-frontend-design.md](docs/superpowers/specs/2026-09-05-tura-frontend-design.md).

## Структура

```
app.py                  точка входа Flask
blueprints/             auth, admin, public_api
rag/                    поиск и генерация ответа
embeddings/             индексация корпуса, работа с векторами
contracts/              шаблоны, генерация, анализ, экспорт договоров
law_generator/          законопроекты: шаблоны, валидация, экспорт
legal_analytics/        анализ общественных комментариев
llm_providers/          абстракция над LLM
database/models.py      модели данных
frontend/               React-приложение TURA
docs/superpowers/specs/ проектные спецификации
scripts/                миграции, индексация, обслуживание
```
